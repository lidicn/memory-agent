## 五、一个我自己的错误（如实记录）

初版 `test_no_match_returns_empty` 我写成：

```python
r = match_device("车库门开了多久", ins)
assert r is not None          # ← 错了
```

实际 `match_device` 在无匹配时返回 `None`，这是**正确语义**，是我的断言写反了。已修正为 `assert r is None` 并在注释中记录。

**这对审计的可信度是必要的**：如果测试"恰好都通过"，反而要怀疑断言是否写反了。
