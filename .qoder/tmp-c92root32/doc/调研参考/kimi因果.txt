MA-行为变化归因 · 设计交付
一、设计决策（§7 要求逐条说明）
1. 数据结构与索引选择
事件索引：search_candidate_causes 需要按时间窗扫描事件，先按 server_ts 排序一次（O(n log n)），后续窗口过滤为 O(n)。不建哈希索引——时间窗查询是范围查询，哈希无益。
统计量：before/after 的 mean/median/std 用 statistics 模块（stdlib），std 用样本标准差（statistics.stdev，n≥2 时），n=1 时 std=0.0。与 behavior_predictor.py 的统计风格保持一致。
Mann-Whitney U：stdlib 无此检验，手写实现。U 统计量 + 正态近似（n>20 时）或查表法（小样本用精确分布的临界值近似）。为简化且稳健，采用秩和正态近似 + 连续性校正，小样本（n<8）时 p 值用保守的精确计算（枚举或查常用临界值表）。
Cohen's d：(mean_after - mean_before) / pooled_std，pooled_std 用合并标准差。
2. 失败/降级语义
表格
场景	语义	理由
事件列表为空 / 该人事件不足	fail-open：changed=False，p_value=1.0，effect_size=0.0，direction="none"	无证据不报警，避免误报轰炸
persons_json 解析失败	跳过该事件	与 behavior_predictor 一致
server_ts 解析失败	跳过该事件	同上
基线或观察期样本数 < 2	无法做统计检验 → changed=False，p_value=1.0	检验无意义
metric="room_distribution" 但无 room 参数	按需求文档，metric 支持 room_distribution 但签名无 room 参数 → 列入"说不清"清单（见下）	不猜
窗口内无候选事件	返回空列表	如实反映
3. 与 §1 现有实现的兼容边界
只读 events 列表，不触碰 store / behavior_predictor / agent_memory。
事件解析逻辑（persons_json、server_ts）与 behavior_predictor 的容错模式逐行对齐：同样的 try/except、同样的 len(ts) < 16 检查、同样的 day = ts[:10] 切法。
不 import behavior_predictor（无依赖），但统计口径（中位数、MAD 思路）风格一致。
4. 需求里说不清的地方（不猜，列出）
room_distribution 指标缺少 room 参数：detect_change 签名是 (events, person, metric, split_ratio)，但文档说 room_distribution "需配合 room 参数"。签名里没有。→ 我的处理：从 metric 字符串解析，支持 "room_distribution:客厅" 格式；若裸写 "room_distribution" 无房间，则 fail-open 返回 changed=False 并在 direction 里说明。这是唯一不破坏签名契约的兼容方案。
候选原因的"时间相关性"定义：文档只说"与行为变化的时间相关性 0~1"，未给公式。→ 我的定义：候选事件在变化窗口内出现的天数占比 × 与变化点的平均时间接近度衰减（指数衰减，半衰期 = lookback_days/2）。
"变化窗口"的精确边界：change_start_ts 是变化开始时间，lookback_days 是回看天数。→ 我的定义：窗口 = [change_start_ts - lookback_days, change_start_ts + lookback_days]，基线期 = 窗口之前的 lookback_days 天数。
activity_count 的"单位时间"：未给单位。→ 用"每天事件数"（按天聚合再平均），最直观。
Mann-Whitney U 小样本精确 p 值：枚举所有排列在 n>8 时不可行。→ n≤8 用精确枚举，n>8 用正态近似。文档未指定，此为常规做法。

"""P4b 行为变化归因：检测行为模式变化并自动搜索候选原因。

因果推理层阶段1（最小可行版本），不引入LLM，纯统计+规则。

核心能力：
1. detect_change()：将事件按时间切分基线/观察期，用 Mann-Whitney U 检验
   + Cohen's d 效应量检测行为指标是否显著变化。
2. search_candidate_causes()：在变化窗口前后搜索候选原因事件
   （设备/人员/环境/日程四类），按综合置信度降序返回。
3. attribute()：完整归因 = detect_change + search_candidate_causes。

与 behavior_predictor.py 的关系：
- behavior_predictor：预测"明天几点回家"（向前看）
- change_attribution：解释"为什么最近回家变晚了"（向后看，找原因）
"""

from __future__ import annotations

import json
import math
import statistics
from collections import defaultdict
from datetime import datetime, timedelta
from typing import Any


# ---------------------------------------------------------------------------
# 内部工具函数
# ---------------------------------------------------------------------------

def _parse_persons(ev: dict) -> list[dict]:
    """解析事件的 persons_json，容错模式与 behavior_predictor 一致。"""
    persons_raw = ev.get("persons_json") or "[]"
    try:
        persons = json.loads(persons_raw) if isinstance(persons_raw, str) else persons_raw
    except (json.JSONDecodeError, TypeError):
        return []
    if not isinstance(persons, list):
        return []
    return persons


def _parse_ts(ev: dict) -> datetime | None:
    """解析事件的 server_ts，容错模式与 behavior_predictor 一致。"""
    ts = ev.get("server_ts", "")
    if not ts or len(ts) < 16:
        return None
    try:
        return datetime.fromisoformat(ts)
    except (ValueError, TypeError):
        return None


def _events_for_person(events: list[dict], person: str) -> list[dict]:
    """过滤出与指定人相关的事件，按时间升序排序。"""
    filtered = []
    for ev in events:
        persons = _parse_persons(ev)
        if not any(p.get("name") == person for p in persons):
            continue
        dt = _parse_ts(ev)
        if dt is None:
            continue
        filtered.append({**ev, "_dt": dt})
    filtered.sort(key=lambda e: e["_dt"])
    return filtered


def _extract_metric_values(
    person_events: list[dict],
    metric: str,
    room: str | None = None,
) -> list[tuple[datetime, float]]:
    """从事件流中提取 (时间戳, 指标值) 序列。

    支持指标：
    - arrival_time：每天第一次出现的小时数（浮点）
    - activity_count：每天的事件数（浮点）
    - room_distribution：某房间事件数 / 当天总事件数（需 room 参数）
    - active_duration：每天最后一次 - 第一次出现的小时数
    """
    # 按天分组
    by_day: dict[str, list[dict]] = defaultdict(list)
    for ev in person_events:
        day = ev["_dt"].strftime("%Y-%m-%d")
        by_day[day].append(ev)

    values: list[tuple[datetime, float]] = []

    for day in sorted(by_day.keys()):
        day_events = sorted(by_day[day], key=lambda e: e["_dt"])
        first_dt = day_events[0]["_dt"]
        last_dt = day_events[-1]["_dt"]

        if metric == "arrival_time":
            val = first_dt.hour + first_dt.minute / 60.0 + first_dt.second / 3600.0
            values.append((first_dt, val))

        elif metric == "activity_count":
            values.append((first_dt, float(len(day_events))))

        elif metric == "active_duration":
            duration_h = (last_dt - first_dt).total_seconds() / 3600.0
            values.append((first_dt, duration_h))

        elif metric == "room_distribution":
            if room is None:
                continue
            room_events = [
                e for e in day_events
                if e.get("room") == room or e.get("scene") == room
            ]
            if len(day_events) > 0:
                values.append((first_dt, len(room_events) / len(day_events)))

    return values


def _mannwhitney_u_pvalue(x: list[float], y: list[float]) -> float:
    """Mann-Whitney U 检验的 p 值（双尾）。

    小样本（n<=8）用精确枚举，大样本用正态近似 + 连续性校正。
    无重叠时返回 0.0（完全显著）。
    """
    n1, n2 = len(x), len(y)
    if n1 < 1 or n2 < 1:
        return 1.0

    combined = [(v, 0) for v in x] + [(v, 1) for v in y]
    combined.sort(key=lambda t: t[0])

    # 计算秩（处理并列）
    ranks = [0.0] * len(combined)
    i = 0
    while i < len(combined):
        j = i
        while j + 1 < len(combined) and combined[j + 1][0] == combined[i][0]:
            j += 1
        avg_rank = (i + j) / 2.0 + 1.0
        for k in range(i, j + 1):
            ranks[k] = avg_rank
        i = j + 1

    R1 = sum(ranks[k] for k in range(len(combined)) if combined[k][1] == 0)
    U1 = R1 - n1 * (n1 + 1) / 2.0
    U2 = n1 * n2 - U1
    U = min(U1, U2)

    # 完全分离：p = 0
    max_U = n1 * n2
    if U <= 0:
        return 0.0

    # 小样本精确计算
    if n1 <= 8 and n2 <= 8:
        return _mw_exact_pvalue(n1, n2, U)

    # 正态近似
    mu = n1 * n2 / 2.0
    # 并列校正
    tie_counts = []
    i = 0
    while i < len(combined):
        j = i
        while j + 1 < len(combined) and combined[j + 1][0] == combined[i][0]:
            j += 1
        if j > i:
            tie_counts.append(j - i + 1)
        i = j + 1
    tie_term = sum(t**3 - t for t in tie_counts)
    N = n1 + n2
    sigma = math.sqrt(
        (n1 * n2 / 12.0) * ((N + 1) - tie_term / (N * (N - 1)))
    )
    if sigma == 0:
        return 1.0
    # 连续性校正
    z = (U - mu + 0.5) / sigma
    # 双尾 p 值：2 * (1 - Phi(|z|))，用误差函数近似
    p = 2.0 * (1.0 - _norm_cdf(abs(z)))
    return max(0.0, min(1.0, p))


def _norm_cdf(z: float) -> float:
    """标准正态 CDF（用 math.erf，stdlib）。"""
    return 0.5 * (1.0 + math.erf(z / math.sqrt(2.0)))


def _mw_exact_pvalue(n1: int, n2: int, U_obs: float) -> float:
    """小样本 Mann-Whitney U 精确双尾 p 值（枚举所有组合）。"""
    from itertools import combinations

    N = n1 + n2
    total = math.comb(N, n1)
    if total == 0:
        return 1.0

    # 枚举所有从 N 个位置中选 n1 个作为组1的方案，计算 U 分布
    # U1 = R1 - n1(n1+1)/2，R1 是组1的秩和
    rank_sum_min = n1 * (n1 + 1) // 2  # 组1占最小的 n1 个秩
    count_le = 0
    for combo in combinations(range(1, N + 1), n1):
        R1 = sum(combo)
        U1 = R1 - rank_sum_min
        U = min(U1, n1 * n2 - U1)
        if U <= U_obs:
            count_le += 1

    p_one_tail = count_le / total
    return min(1.0, 2.0 * p_one_tail)


def _cohens_d(before: list[float], after: list[float]) -> float:
    """Cohen's d（合并标准差版本）。"""
    if len(before) < 2 or len(after) < 2:
        return 0.0
    m1, m2 = statistics.mean(before), statistics.mean(after)
    s1, s2 = statistics.stdev(before), statistics.stdev(after)
    n1, n2 = len(before), len(after)
    pooled = math.sqrt(((n1 - 1) * s1**2 + (n2 - 1) * s2**2) / (n1 + n2 - 2))
    if pooled == 0:
        # 两组都无方差：看均值差
        return 0.0 if m1 == m2 else float("inf") if abs(m2 - m1) > 0 else 0.0
    return (m2 - m1) / pooled


def _period_str(dts: list[datetime]) -> str:
    """生成 'YYYY-MM-DD~YYYY-MM-DD' 格式的周期字符串。"""
    if not dts:
        return ""
    days = sorted(d.strftime("%Y-%m-%d") for d in dts)
    return f"{days[0]}~{days[-1]}"


def _stats_block(values: list[float], dts: list[datetime]) -> dict:
    """生成 before/after 统计块。"""
    if not values:
        return {"mean": 0.0, "median": 0.0, "std": 0.0, "count": 0, "period": ""}
    return {
        "mean": round(statistics.mean(values), 4),
        "median": round(statistics.median(values), 4),
        "std": round(statistics.stdev(values), 4) if len(values) > 1 else 0.0,
        "count": len(values),
        "period": _period_str(dts),
    }

# 候选原因事件类型映射
_CAUSE_TYPE_MAP: dict[str, str] = {
    # 设备状态变化
    "light_on": "device_change",
    "light_off": "device_change",
    "tv_on": "device_change",
    "tv_off": "device_change",
    "aircon_on": "device_change",
    "aircon_off": "device_change",
    # 人员变化
    "face_known": "person_change",
    "face_unknown": "person_change",
    # 环境变化
    "door_open": "environment_change",
    "door_close": "environment_change",
    "window_open": "environment_change",
    "window_close": "environment_change",
}


def _count_events_by_type(
    events: list[dict],
    start: datetime,
    end: datetime,
) -> dict[str, int]:
    """统计时间窗内各事件类型出现次数。"""
    counts: dict[str, int] = defaultdict(int)
    for ev in events:
        dt = _parse_ts(ev)
        if dt is None:
            continue
        if start <= dt <= end:
            action = ev.get("action") or "unknown"
            counts[action] += 1
    return dict(counts)


def _days_present(
    events: list[dict],
    action: str,
    start: datetime,
    end: datetime,
) -> int:
    """某事件类型在时间窗内出现的天数。"""
    days = set()
    for ev in events:
        dt = _parse_ts(ev)
        if dt is None:
            continue
        if ev.get("action") == action and start <= dt <= end:
            days.add(dt.strftime("%Y-%m-%d"))
    return len(days)


def search_candidate_causes(
    events: list[dict],
    person: str,
    change_start_ts: str,
    lookback_days: int = 7,
) -> list[dict]:
    """在行为变化发生前后的时间窗口内，搜索可能导致变化的候选原因事件。

    窗口定义：[change_start - lookback_days, change_start + lookback_days]
    基线期：[change_start - 2*lookback_days, change_start - lookback_days]

    候选原因类型: 设备状态变化、人员变化、环境变化、日程相关。
    返回按置信度降序的候选原因列表。
    """
    try:
        change_dt = datetime.fromisoformat(change_start_ts)
    except (ValueError, TypeError):
        return []

    window_start = change_dt - timedelta(days=lookback_days)
    window_end = change_dt + timedelta(days=lookback_days)
    baseline_start = change_dt - timedelta(days=2 * lookback_days)
    baseline_end = change_dt - timedelta(days=lookback_days)

    window_counts = _count_events_by_type(events, window_start, window_end)
    baseline_counts = _count_events_by_type(events, baseline_start, baseline_end)

    candidates: list[dict] = []

    # 1. 映射表内的事件类型
    for action, cause_type in _CAUSE_TYPE_MAP.items():
        w_count = window_counts.get(action, 0)
        b_count = baseline_counts.get(action, 0)
        if w_count == 0 and b_count == 0:
            continue

        # 时间相关性：窗口内出现天数占比 × 时间接近度衰减
        days_in_window = _days_present(events, action, window_start, window_end)
        window_days_total = (window_end - window_start).days + 1
        day_ratio = days_in_window / window_days_total if window_days_total > 0 else 0.0

        # 时间接近度：候选事件平均时间与 change_dt 的接近程度
        proximity = _avg_temporal_proximity(events, action, window_start, window_end, change_dt)

        correlation = round(day_ratio * 0.5 + proximity * 0.5, 4)

        # 置信度：相关性 × 变化幅度因子
        if b_count == 0:
            magnitude = 1.0 if w_count > 0 else 0.0
        else:
            magnitude = min(1.0, abs(w_count - b_count) / b_count)
        confidence = round(correlation * (0.5 + 0.5 * magnitude), 4)

        # 描述
        if b_count == 0:
            desc = f"变化前后{lookback_days}天内{action}出现了{w_count}次（基线期为0次）"
        else:
            pct = round((w_count - b_count) / b_count * 100)
            desc = f"变化前后{lookback_days}天内{action}出现次数较基线期变化了{pct}%（{b_count}→{w_count}次）"

        candidates.append({
            "cause_type": cause_type,
            "event_type": action,
            "count": w_count,
            "baseline_count": b_count,
            "correlation": correlation,
            "confidence": confidence,
            "description": desc,
        })

    # 2. 日程相关：weekday / weekend / holiday 模式变化
    schedule_candidates = _detect_schedule_changes(
        events, person, window_start, window_end, baseline_start, baseline_end, lookback_days
    )
    candidates.extend(schedule_candidates)

    # 按置信度降序
    candidates.sort(key=lambda c: -c["confidence"])
    return candidates


def _avg_temporal_proximity(
    events: list[dict],
    action: str,
    start: datetime,
    end: datetime,
    change_dt: datetime,
) -> float:
    """候选事件与变化点的时间接近度（指数衰减，半衰期=窗口天数/2）。"""
    dts = []
    for ev in events:
        dt = _parse_ts(ev)
        if dt is None:
            continue
        if ev.get("action") == action and start <= dt <= end:
            dts.append(dt)
    if not dts:
        return 0.0
    half_life_days = max(1.0, (end - start).days / 2.0)
    decay_sum = 0.0
    for dt in dts:
        delta_days = abs((dt - change_dt).total_seconds()) / 86400.0
        decay_sum += math.exp(-math.log(2) * delta_days / half_life_days)
    return decay_sum / len(dts)


def _detect_schedule_changes(
    events: list[dict],
    person: str,
    window_start: datetime,
    window_end: datetime,
    baseline_start: datetime,
    baseline_end: datetime,
    lookback_days: int,
) -> list[dict]:
    """检测日程相关变化：工作日/周末行为模式变化。"""
    candidates = []

    # 统计窗口 vs 基线期内，该人在工作日/周末的出现次数
    def _count_weekdays(start: datetime, end: datetime) -> tuple[int, int]:
        wd, we = 0, 0
        for ev in events:
            persons = _parse_persons(ev)
            if not any(p.get("name") == person for p in persons):
                continue
            dt = _parse_ts(ev)
            if dt is None:
                continue
            if start <= dt <= end:
                if dt.weekday() < 5:
                    wd += 1
                else:
                    we += 1
        return wd, we

    w_wd, w_we = _count_weekdays(window_start, window_end)
    b_wd, b_we = _count_weekdays(baseline_start, baseline_end)

    # 工作日模式变化
    if b_wd > 0 and w_wd > 0:
        ratio_change = abs(w_wd - b_wd) / b_wd
        if ratio_change > 0.3:  # 变化超过30%才报告
            correlation = min(1.0, ratio_change)
            confidence = round(correlation * 0.6, 4)
            candidates.append({
                "cause_type": "schedule_change",
                "event_type": "weekday_pattern",
                "count": w_wd,
                "baseline_count": b_wd,
                "correlation": round(correlation, 4),
                "confidence": confidence,
                "description": f"变化前后{lookback_days}天内工作日出现次数变化了{round(ratio_change*100)}%（{b_wd}→{w_wd}次）",
            })

    # 周末模式变化
    if b_we > 0 and w_we > 0:
        ratio_change = abs(w_we - b_we) / b_we
        if ratio_change > 0.3:
            correlation = min(1.0, ratio_change)
            confidence = round(correlation * 0.6, 4)
            candidates.append({
                "cause_type": "schedule_change",
                "event_type": "weekend_pattern",
                "count": w_we,
                "baseline_count": b_we,
                "correlation": round(correlation, 4),
                "confidence": confidence,
                "description": f"变化前后{lookback_days}天内周末出现次数变化了{round(ratio_change*100)}%（{b_we}→{w_we}次）",
            })

    return candidates

def detect_change(
    events: list[dict],
    person: str,
    metric: str,
    split_ratio: float = 0.5,
) -> dict:
    """检测某人的行为指标是否发生显著变化。

    将事件按时间排序后，按 split_ratio 分成前半段（基线）和后半段（观察期）。
    metric 支持: "arrival_time"、"activity_count"、"room_distribution[:房间名]"、"active_duration"。
    返回含 changed/metric/person/before/after/effect_size/p_value/direction。
    """
    # 解析 room_distribution 的房间参数（契约外的兼容方案）
    room: str | None = None
    effective_metric = metric
    if metric.startswith("room_distribution"):
        if ":" in metric:
            effective_metric, room = metric.split(":", 1)
        else:
            # 裸 room_distribution 无房间参数 → fail-open
            return {
                "changed": False,
                "metric": metric,
                "person": person,
                "before": {"mean": 0.0, "median": 0.0, "std": 0.0, "count": 0, "period": ""},
                "after": {"mean": 0.0, "median": 0.0, "std": 0.0, "count": 0, "period": ""},
                "effect_size": 0.0,
                "p_value": 1.0,
                "direction": "none",
            }

    person_events = _events_for_person(events, person)
    values = _extract_metric_values(person_events, effective_metric, room)

    # 样本不足 → fail-open
    if len(values) < 4:
        return {
            "changed": False,
            "metric": metric,
            "person": person,
            "before": {"mean": 0.0, "median": 0.0, "std": 0.0, "count": 0, "period": ""},
            "after": {"mean": 0.0, "median": 0.0, "std": 0.0, "count": 0, "period": ""},
            "effect_size": 0.0,
            "p_value": 1.0,
            "direction": "none",
        }

    # 按 split_ratio 切分
    split_idx = max(1, min(len(values) - 1, int(len(values) * split_ratio)))
    before_vals = [v for _, v in values[:split_idx]]
    after_vals = [v for _, v in values[split_idx:]]
    before_dts = [d for d, _ in values[:split_idx]]
    after_dts = [d for d, _ in values[split_idx:]]

    # 统计量
    before_block = _stats_block(before_vals, before_dts)
    after_block = _stats_block(after_vals, after_dts)

    # 检验需要每组至少 2 个样本
    if len(before_vals) < 2 or len(after_vals) < 2:
        return {
            "changed": False,
            "metric": metric,
            "person": person,
            "before": before_block,
            "after": after_block,
            "effect_size": 0.0,
            "p_value": 1.0,
            "direction": "none",
        }

    effect = _cohens_d(before_vals, after_vals)
    p_val = _mannwhitney_u_pvalue(before_vals, after_vals)

    # 方向
    diff = after_block["mean"] - before_block["mean"]
    if abs(diff) < 1e-9:
        direction = "none"
    else:
        direction = "increase" if diff > 0 else "decrease"

    # 判定：p < 0.05 且 |effect| > 0.5
    changed = bool(p_val < 0.05 and abs(effect) > 0.5)

    return {
        "changed": changed,
        "metric": metric,
        "person": person,
        "before": before_block,
        "after": after_block,
        "effect_size": round(effect, 4) if math.isfinite(effect) else 999.0,
        "p_value": round(p_val, 6),
        "direction": direction,
    }


def attribute(
    events: list[dict],
    person: str,
    metric: str,
    split_ratio: float = 0.5,
    lookback_days: int = 7,
) -> dict:
    """完整归因：先检测变化，再搜索候选原因。

    返回 detect_change() 的全部字段 + candidate_causes 字段。
    如果 changed=False，candidate_causes 返回空列表。
    """
    change_result = detect_change(events, person, metric, split_ratio)
    result = dict(change_result)

    if not change_result["changed"]:
        result["candidate_causes"] = []
        return result

    # 变化点：观察期的开始时间
    after_period = change_result["after"]["period"]
    if after_period and "~" in after_period:
        change_start = after_period.split("~")[0]
    else:
        # 退化：用最后一个事件时间
        person_events = _events_for_person(events, person)
        if person_events:
            change_start = person_events[-1]["_dt"].strftime("%Y-%m-%dT%H:%M:%S")
        else:
            result["candidate_causes"] = []
            return result

    candidates = search_candidate_causes(events, person, change_start, lookback_days)
    result["candidate_causes"] = candidates
    return result

def _make_arrival_events(
    person: str,
    start_date: datetime,
    num_days: int,
    arrival_hour: float,
    jitter: float = 0.1,
    actions: list[str] | None = None,
    seed: int = 42,
) -> list[dict]:
    """构造某人到家事件序列。

    arrival_hour: 到家时间（小时浮点，如 18.5 = 18:30）
    jitter: 随机扰动幅度（小时）
    """
    rng = random.Random(seed)
    events = []
    for i in range(num_days):
        day = start_date + timedelta(days=i)
        h = arrival_hour + rng.uniform(-jitter, jitter)
        h = max(0.0, min(23.9, h))
        hh, mm = int(h), int((h % 1) * 60)
        ts = day.replace(hour=hh, minute=mm, second=0).strftime("%Y-%m-%dT%H:%M:%S")
        events.append(_make_event(ts, action="face_known", persons=[{"name": person, "confidence": 0.9}]))
        # 附加一些活动事件
        if actions:
            for j, act in enumerate(actions):
                act_ts = day.replace(hour=hh, minute=min(59, mm + 5 * (j + 1)), second=0)
                events.append(_make_event(
                    act_ts.strftime("%Y-%m-%dT%H:%M:%S"),
                    action=act,
                    persons=[{"name": person, "confidence": 0.9}],
                ))
    return events

def make_demo_events() -> list[dict]:
    """构造演示数据：Kevin 的到家时间从 18:00 推迟到 21:00，且电视打开次数激增。"""
    events = []
    base = datetime(2026, 9, 1)

    # 基线期（9/1-9/10）：18:00 到家，看 1 小时电视
    for i in range(10):
        day = base + timedelta(days=i)
        events.append({
            "id": i * 10 + 1,
            "server_ts": day.replace(hour=18, minute=0).strftime("%Y-%m-%dT%H:%M:%S"),
            "action": "face_known",
            "scene": "客厅",
            "room": "客厅",
            "persons_json": json.dumps([{"name": "Kevin", "confidence": 0.95}]),
            "source": "vision",
            "confidence": 0.95,
        })
        events.append({
            "id": i * 10 + 2,
            "server_ts": day.replace(hour=19, minute=0).strftime("%Y-%m-%dT%H:%M:%S"),
            "action": "tv_on",
            "scene": "客厅",
            "room": "客厅",
            "persons_json": json.dumps([{"name": "Kevin", "confidence": 0.9}]),
            "source": "edge_ai",
            "confidence": 0.9,
        })

    # 观察期（9/11-9/20）：21:00 到家，看 4 小时电视
    for i in range(10, 20):
        day = base + timedelta(days=i)
        events.append({
            "id": i * 10 + 1,
            "server_ts": day.replace(hour=21, minute=0).strftime("%Y-%m-%dT%H:%M:%S"),
            "action": "face_known",
            "scene": "客厅",
            "room": "客厅",
            "persons_json": json.dumps([{"name": "Kevin", "confidence": 0.95}]),
            "source": "vision",
            "confidence": 0.95,
        })
        for j in range(4):
            events.append({
                "id": i * 10 + 2 + j,
                "server_ts": day.replace(hour=21, minute=j * 15 + 5).strftime("%Y-%m-%dT%H:%M:%S"),
                "action": "tv_on",
                "scene": "客厅",
                "room": "客厅",
                "persons_json": json.dumps([{"name": "Kevin", "confidence": 0.9}]),
                "source": "edge_ai",
                "confidence": 0.9,
            })

    return events


# ========== 2. 检测变化 ==========

events = make_demo_events()
