## 已知风险 / 注意

- **来源白名单**：`agent_memory_sources` 默认 `["ma","butler","vision","manual"]`，如需新来源须在 config 扩展；当前 UI 仅下发 `ma`/用户自建来源。
- **多令牌存储位置**：写入 `config.app_tokens`（config.json），落盘为 hash；`_touch` 节流写盘。旧单 `app_token`（env `APP_TOKEN`）仍作为兜底生效。
- **合并拆分**：`split` 把 auto-merged 设备拆为各候选独立 `user-pinned` 设备，对账时不再被 A2 自动重合并；会同步把 `device_health.stable_id` 指回新设备。模板按逻辑名解析，不受 stable_id 变化影响。
- **MQTT 周期重连**：默认 30s 退避（可在 `.env` 配 `MA_MQTT_RECONNECT_INTERVAL`）；建连后 broker 抖动由 paho 自动重连。
