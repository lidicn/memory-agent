# 调研 · MA 断板:感知算法 / 融合算法 / 用户行为推测(开源方案)

> 制定日期:2026-09-17
> 背景:Frigate 已**暂不考虑**(NAS=J3455/Apollo Lake 无 AVX2,Frigate 人脸跑不了;且现有 doubao2api 多模态 + ArcFace 已覆盖语义)。本调研转向 MA **当前真正短板**:感知算法、融合算法、用户行为推测。
> 方法:① 实测 MA 当前代码(`activity_inference.py` / `identity.py`);② 并行调研外部开源项目,按"能否直接复用 / 仅借鉴"分类。

## 0 · 结论速览

1. **MA 当前三层均为确定性规则/启发式,零统计/概率/学习成分**:
   - 感知:3 条手写 `DEFAULT_SEQUENCE_RULES` + 朴素 n-gram 频次挖掘。
   - 融合:`difflib` 字符串相似度(≥0.85)合并实体;身份双源(last-seen 覆盖)。
   - 行为推测:习惯=众数小时;无漂移/异常/预测。
2. **可直接复用的库**(低风险、替换手写逻辑):
   - `pm4py` —— 替代 `mine_sequences` 的朴素 n-gram,做真正的**过程挖掘**(行为过程模型 + 一致性检验=异常)。
   - `river` —— 在线学习 + 行为**异常检测** + **概念漂移**检测(行为随时演变)。
   - `hmmlearn`/`pomegranate` —— 用 **HMM** 从稀疏二进制传感器事件推断隐藏活动状态,天然处理不确定/部分观测。
3. **可借鉴架构(非直接替换)**:
   - `Zep/Graphiti` —— 时序知识图谱记忆层(实体-关系-时间),MA 记忆层从"扁平文本+时间戳"演进方向。
   - `Splink` —— 概率记录链接(Fellegi-Sunter),升级 `identity.py` 实体解析为带匹配概率。
   - `CASAS` —— 真实家居活动识别数据集/算法范式(HMM/CRF/DBN),供算法参考。
4. **需新增调研的核心算法**:概率活动识别(HMM/CRF/DBN)、时序知识图谱、变化点检测、行为异常、概率实体解析、行为预测/意图推断、多模态原则融合。

## 1 · MA 当前三层的实测短板

### 1.1 感知层(活动推断)—— `activity_inference.py`
- `run()` 用 **3 条硬编码规则**(`书房工作`/`就寝`/`房间移动`)+ `_match_rule` 有序序列匹配 + PIR 去抖。**新增活动必须手写规则**。
- `mine_sequences()` = 朴素 n-gram 频次(max_len=4, support≥min_support),**无约束、无噪声建模、无并行/循环结构**。
- `infer_habits()` = 按 (member, activity) 聚合 → 取众数小时 → 文本记忆。**无漂移、无预测、无异常**。
- **缺**:概率活动识别、视觉文本+传感器+人脸的**原则性多模态融合**、时序状态建模(活动内的连续状态)。

### 1.2 融合层(身份 + 记忆)—— `identity.py` + 行为状态
- `identity.py`:`difflib.SequenceMatcher` 相似度 ≥ 0.85 + 公共前缀 ≥ 6 字符,按 (room, domain) 聚类。**启发式字符串匹配,无概率、无学习**。
- 身份融合:`recent_presence` 双源(客厅盒侧 + ArcFace),`current_behaviors` 里 `room_member` 用 last-seen 直接覆盖,**无冲突解决、无置信组合**。
- 记忆融合:已有 mem0 式向量合并,但**无时序知识图谱**(实体-关系随时间演变)。
- **缺**:概率实体解析、多源冲突解决、时序知识图谱、事件流响应式处理。

### 1.3 行为推测层
- 习惯=众数小时;`member_schedule` 已有 valid_from/valid_to 时间切片(作息演变可追溯)——这块 MA 反而领先。
- **缺**:行为漂移检测(变化点)、异常行为检测、行为预测/下一步、意图推断、按成员聚类行为模式。

## 4 · 需新增调研的核心算法(当前不足清单)

1. **概率活动识别**:HMM / CRF / DBN 从稀疏二进制传感器推断活动;不确定性传播;部分观测处理。
2. **时序知识图谱(TKG)**:实体-关系-时间三元组;时间窗口查询;冲突消解(谁在何时在哪)。
3. **变化点检测**:行为漂移(睡眠时段迁移等),ruptures / 贝叶斯变点。
4. **行为异常检测**:分布外检测(river / PyOD)+ 过程挖掘一致性偏差。
5. **概率实体解析**:多源身份融合(Fellegi-Sunter),匹配概率 + 冲突解决。
6. **行为预测 / 意图推断**:下一活动预测(马尔可夫 / 序列模型 / LLM)。
7. **多模态原则融合**:视觉文本 + 传感器 + 人脸的贝叶斯 / 证据理论融合(替代当前证据求和)。

---

## 5 · 优先级建议(落地顺序)

- **P1(低风险高收益,直接复用库)**:① `pm4py` 替代手写 n-gram(行为过程模型 + 一致性异常);② `river` 行为异常 + 漂移;③ `hmmlearn` 活动 HMM 试点(替代一条手写规则验证)。
- **P2(融合升级)**:④ `Splink` 升级 `identity.py` 实体解析;⑤ 多源身份概率融合(客厅盒侧 + ArcFace 冲突解决)。
- **P3(记忆层演进)**:⑥ 评估 `Zep/Graphiti` 时序 KG 迁移(大改,需单独立项)。
- **P4(预测/意图)**:⑦ 行为预测 + 意图推断。

> P1 三项都能**直接 pip 引入、替换手写逻辑、单测可验**,是性价比最高的起点,建议作为【主动感知】v2.0 的算法内核。
