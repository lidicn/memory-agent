## 八、量具纪律：会造假绿／假红的形状（本席位踩实过的，共 14 条）

1. 判据取**调用点（AST）**，⛔ 取文本面：docstring／出货文案里写"宿主脚本执行 git pull"会把"容器⛔ 执行 git"读成**恒红**（本批第一腿就是这么红的）。
2. **恒绿的判据⛔ 是判据**（`host_update.sh:44` `[ ! -f "$MARKER" ] && exit 0`）；"可用"与"被调到"是两件事。
3. 恒红也⛔ 可用——⛔ 恒红恒绿一对都要防；判据红了先找反例。
4. 报 0 命中前先出**正控＋反控**，且与"0 命中"那跑**同批出**（⛔ 事后补）。
5. **命中数⛔ 是判据**（`.qoder` 副本树会灌满搜索结果，Grep 会打 250 上限）；存在性判据用 `find`（`ls` 非递归＝假 0）。
6. 跨仓／跨席位对撞前先**pin grep 口径**（`HEAD`／index／工作树 三面各跑；`--cached` 必须排在 `-e` 之前，否则被当 pathspec 吃掉＝假绿）。
7. 转抄对端名单的锁只锁得住**自己这一边**；手抄名单的任何 `NAKED` 都只是**下界**。
8. 变异自证跑在**副本树**（⛔ 碰工作树）；注入前先 `ast.parse`／先撞命中数，⛔ 符即作废该子例；多处命中的注入要**逐处全改**（只改一处腿照样绿＝假杀）；先跑 Q-0 pristine，Q-0 ⛔ 绿 ⇒ 整轮作废。
9. 长跑在飞时新加的 `tests/` 文件⛔ 被那一跑收集 ⇒ 落册必须写"取在新增文件之前"；`pytest -k` 会把具名 id 也过滤掉（具名腿＋关键字腿合在一条命令＝具名那条没跑）。
10. 失败腿归属要**逐枚读原文**：跑红门的子进程腿是连坐；旧计数⛔ 删只加指路。
11. 判"未做／不存在"前先读**该工具自己的射程**与它 `tests/` 里的自锁；否定句要带面名＋取法＋正控。

- 台账／长文追加用**引号 heredoc**（`cat >> f <<'EOF'`）保 `\\`；⛔ Python 文本模式重写文件（会把 LF 整份改成 CRLF，diff 变全文件重写）；批量改行用 `read_bytes`／`newline=''`。
- ⛔ `b'…'` 里放中文；⛔ 串内嵌 ASCII 双引号（编译期就炸，文件未改，可安全重试）。
- ⛔ `open(p,'wb')` 与可能失败的表达式串在一行（`open(p,'wb').write(A+B)` 先截断再报错＝原文件清空，踩过一次，靠 `git restore` 救）。
- guard 脚本少参会当场死；`$(…)` 会覆盖 `$?`；后台通知的 exit code 是**整条复合命令**的；`grep` 0 命中会断 `&&` 链；批量 `cmp` 拼靶名炸出 `RC=2` ⛔ 那是读数。
- Markdown 表格里竖线要写 `\|`；写完自检：`sed -n 'A,Bp' f | grep -nF '\|' | grep -v '^[0-9]*:|'` ⇒ 无输出＝转义都在表格行内。
