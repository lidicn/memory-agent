## 一、P0：infer_activities 语义层完全失效，退化为时段兜底

请求：infer_activities(days=3)

返回摘要自曝其短：

    summary: { count: 5, by_name: {晨间活动: 4, 可能离家: 1},
               days: 4, semantic: 0, heuristic: 5 }

semantic=0、heuristic=5 —— 5 条活动**全部**由时段启发式产生，语义规则命中为 0。文档宣称可识别「做饭/洗澡/睡眠/看电视/离家」，实测一条都没识别出来。

### 三处自相矛盾

1. **晨间活动覆盖全天**：2026-10-06 的记录 start_hour=0、end_hour=23，横跨 00:00-23:59。名为「晨间」，实际覆盖整个自然日，标签与内容完全脱节。
2. **room 全部为空**：5 条活动的 room 字段均为空字符串，无法回答「哪个房间在干什么」。
3. **主导域是遥测**：evidence 明写「主导域 sensor」——事件构成中 sensor 占绝大多数（如 10-06：sensor 37334 / 总 41369 = 90%）。所谓「活动」实为传感器轮询计数。

### 采样截断，结论不完整

    rule_sources: { events_scanned: 30000, events_total: 116535,
                    scan_limit: 30000, scan_truncated: true }

只扫描了 **30000 / 116535 = 25.7%** 的事件，且 scan_truncated=true。用户在不知情下拿到一份基于四分之一数据的「活动报告」。

与 R1-D3/D12 同根：遥测污染从画像渗到规则，现已渗到活动识别。

## 三、P1：get_behavior_insights_compare 分母口径不一致

请求：get_behavior_insights_compare(compare_days=7)

    current:  total_events=210141, active_days=8, avg_per_day=30020.14
    previous: total_events=182060, active_days=8, avg_per_day=26008.57

验算：

    210141 / 7 = 30020.14   ← 实际分母
    210141 / 8 = 26267.61
    182060 / 7 = 26008.57   ← 实际分母

同一个对象里 active_days=8 与 avg_per_day（按 7 除）并存，两个口径打架。窗口 10-01 07:54 至 10-08 07:54 恰为 7 天，但按自然日切片得 8 天。工具**未说明**用哪个口径，使用者无法判断「日均」到底除以几。

## 四、P1：get_climate_sessions 会话状态自相矛盾

请求：get_climate_sessions(days=3)

书房空调会话：

    entity_id: climate.lumi_cn_84159632_v2
    start: 2026-10-05T14:57:25
    end:   2026-10-07T11:00:22
    duration_minutes: 2642
    still_on: true
    notes: [窗口结束时仍未收到 off，会话未闭合，duration 为「至今」时长]

矛盾：still_on=true 表示「未闭合」，但 end 却是一个**早于窗口结束**（10-08 07:54）的具体时间 10-07T11:00:22。若未闭合，end 应为窗口右沿；若已闭合，still_on 应为 false。二者不能同真。

验算时长：10-05 14:57 至 10-07 11:00 = 44.05 小时 = 2643 分钟，与 duration_minutes=2642 相符——说明 end 被当作真实结束点参与计算，但状态又标 still_on。

### 附带：温度覆盖不全

    sessions_with_temperature: 2 / 4
    temperature_note: 采集端在本次修复后才开始全量快照温度，
                      早于修复时间的历史会话仍会是 null

4 个会话仅 2 个有温度（50%）。书房会话 room_temp_c=null、samples.room_temp=0。工具主动披露了原因，这点应予肯定。
