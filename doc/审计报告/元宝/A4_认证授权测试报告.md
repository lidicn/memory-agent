## 三、P3-8　账号级 DoS：跨 IP 累计失败锁定账号

**位置**：`src/memory_agent/auth.py:231` `_login_keys`

```python
def _login_keys(ip: str, username: str) -> list:
    return [f"ip:{ip}", f"user:{username}"]
```

失败计数**同时累加到 IP 键和用户名键**，任一键达到阈值即锁定两个键。

### 实测

```
6 个不同 IP，每个 IP 对 bob 错 1 次（远低于阈值 5）：

  10.0.0.0     允许登录=False
  10.0.0.5     允许登录=False
  99.99.99.99  允许登录=False   ← 从未尝试过的 IP 也被锁
```

### 攻击链

攻击者从 N 个 IP（或伪造源 IP）各试 1 次错误密码 → `user:bob` 计数达 5 → **账号被锁 30 分钟**（`_LOGIN_LOCK_SECONDS = 1800`）。

合法用户在**完全没输错**的情况下无法登录。

### 与单 IP 场景的对比

| 场景 | 效果 |
|---|---|
| 单 IP 连错 5 次 | 锁定该 IP —— **正确**，防爆破 |
| 6 个 IP 各错 1 次 | 锁定账号全局 —— **缺陷**，账号级 DoS |

### 定级 P3 而非 P2

- 需要攻击者有能力发起多 IP 请求（家庭内网场景下门槛较高）
- 锁定 30 分钟可自愈，非永久
- 不影响数据机密性，仅影响可用性

### 修复建议

用户名键的阈值应显著高于 IP 键（如 IP 5 次、用户名 20 次），或用户名键只记失败**次数**用于告警、不用于锁定。
