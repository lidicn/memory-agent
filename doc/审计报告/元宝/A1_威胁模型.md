## 一、资产识别

| 资产 | 敏感度 | 位置 |
|---|---|---|
| HA 历史时序数据 | 高（家庭行为全量） | SQLite / ChromaDB |
| 家庭行为画像（作息/到家时间） | 高（隐私推断） | store / insights |
| 人脸特征与身份绑定 | **最高**（生物特征） | face_routes / vision / identity |
| JWT 凭据（jwt_secret） | 高 | config |
| HA Token（hass_token） | 高（可操控家居） | config |
| LLM API Key | 中（成本/配额） | config |
| MCP Auth Token / agent_tokens | 高 | config |
| 成员档案、位置在场 | 高 | member_routes |

## 二、信任边界

| 边界 | 对侧 | 校验机制 |
|---|---|---|
| WebUI 用户 | 浏览器 | JWT（AuthMiddleware 白名单模式） |
| MCP 客户端 | LLM / Agent | mcp_auth_token + scope |
| Node-RED 流 | 内网自动化 | nr_routes（**需重点审查**） |
| HA Assist | HA 会话集成 | ha_assist_token（独立） |
| 人脸节点（TV/手机） | 设备端 | vision_device_token（独立） |
| 豆包管家 | 外部服务 | butler_token（窄白名单） |
| AutoFlow 竞技场 | 外部 | arena token（ARENA_ENDPOINTS 白名单） |
| ACP | 外部 | acp token |

## 四、鉴权架构评估（已验证）

**结论：架构正确，采用白名单默认拒绝模式。**

```
PUBLIC_EXACT   = {"/", "/index.html", "/health", "/sw.js", "/manifest.webmanifest"}
DEVICE_ENDPOINTS (独立 token)  = /api/events/face, /api/face/node/*
HA_ENDPOINTS     (独立 token)  = /v1/chat/completions, /v1/models
BUTLER_ENDPOINTS (窄白名单)
ARENA_ENDPOINTS  (白名单)
```

39 个"无 require_* 显式调用"的路由处理函数，经核查为：
1. 依赖 AuthMiddleware 集中鉴权（arena_routes / insight_routes 等，文档已说明）
2. helper 函数（`_client_ip` / `runtime` / `current_user`）
3. auth_routes 自身的 login/register（本就不应鉴权）

**非缺陷。** 但需在 P3 阶段验证 AuthMiddleware 是否真正覆盖所有非白名单路径。
