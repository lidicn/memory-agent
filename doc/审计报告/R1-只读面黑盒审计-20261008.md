## 一、P0 缺陷（4 项）

### D1 list_device_health：非法枚举值静默返回空集

    list_device_health(state="all", fields="full", limit=5000)
    → ok=true, health=[], total=0, limit=2000(被夹), logical_devices=1267

state 仅接受 active/unknown/stale，传 "all" 既不报错也不回落全量，返回空集。使用者会读成“设备全健康”，实际是过滤筛空了一切。

期望：非法枚举值返回 INVALID_PARAM；或 state 缺省=全量。

### D2 ask_memory：路由解析正确，执行层空转

    ask_memory(question="昨天谁在家做饭", route="semantic", days=2)
    plan: room=厨房 activity=cooking 时间=2026-10-07（解析全对）
    answer: "我还不确定你想问什么。试试：最近 7 天有哪些活动；试试：昨天洗澡了吗"
    data: {hints:[同上两条]}, total=1，无实际数据

解析正确却回吐硬编码兜底话术，语义召回失败被静默降级。

### D9 get_user_persona：结论随窗口漂移（新）

    days=3 → 作息类型=“日间活跃型”, peak_hour=20
    days=7 → 作息类型=“早起型”,   peak_hour=5

同一用户换窗口得出相反结论。7 天 hourly 实测全天 7225~11727，5 点峰值 11727、16 点谷值 7678，无真正夜间低谷。结论是“贴”上去的，不是算出来的。

### D10 query_device_usage：违背自身核心承诺（新）

    query_device_usage(logical_device="客厅电视", metric="duration", days=2)
    → ok=true, result={error:"设备已失效或待重匹配，请检查实体身份层", stale:true}

该工具文档宣称“identity layer 解析，entity_id 漂移后依然稳定”，实测直接失效。且 ok=true 却携带 error，又一次失败不报错。

## 二、P1 缺陷（4 项）

### D3 画像遥测污染

get_user_persona 的 top_entities 前 10 全为 sensor.*（线圈温度/CO2/功耗/存储空间）。“设备交互强度 30036 次/天”绝大部分是轮询噪声。对照 get_behavior_summary 有 telemetry_excluded，两工具口径不一致。

### D4 日记空壳入库

    read_self_diary(days=7) → count=2,
    diaries=[{date:"2026-10-06",text:""},{date:"2026-10-07",text:""}]

有日期无正文。写入失败落空壳，读取不校验。

### D11 规则闭环卡死 staging（升级）

    list_candidate_rules(status=staging) → count=24
    list_rule_channel → promoted_rules={dry_run:[],live:[],revoked:[]}
    list_rule_lifecycle_audit → count=0

24 条候选规则 100% 卡在 staging，无一进入 accept/promote/dry_run/live。闭环从未跑通。

### D12 遥测污染渗入规则挖掘（新）

候选规则 steps 含遥测实体：sensor.xiaomi_cn_533439795_mt0_outdoor_mach_current_p_12_13 被当作“卧室/房间移动”的两步。与 D3 同根。

## 三、P2 缺陷（5 项）

### D5 撤销未回填 revoked_at

    list_signal_rules(include_revoked=true)
    → exclusion_id=5e13db3466e79f2b, revoked=true, revoked_at=null, reason=""

撤销只翻标志位，未写审计时间戳与理由。“可回滚”红线留痕残缺。

## 七、总体判断

架构意图清晰、契约设计规范，但缺陷高度集中在同一模式：**失败路径不报错**。

- 非法参数 → 返回空集
- 召回失败 → 回吐兜底话术
- 解析失败 → 硬返回 ok=true + error
- 分布平坦 → 硬贴作息标签
- 24 条候选卡死 → channel 硬报“全空”

对使用者而言，最危险的从来不是报错，而是看起来成功的错误答案。
