## 一、项目概览

**memory-agent** 是家庭行为记忆中枢，运行在 NAS Docker 容器中，负责：
- 采集 Home Assistant 事件（设备状态变化、人员在场）
- 推断家庭成员活动（睡眠/烹饪/学习等）
- 存储行为记忆（SQLite + Chroma 向量库）
- 提供 MCP 工具（49 个）供下游（管家 DB / AutoFlow AF / TV端）查询
- 主动学习（候选规则生成 + 用户确认）

**技术栈**：Python 3.11+ / FastAPI / SQLite (WAL) / ChromaDB / MCP 2.x / pymysql (HA MariaDB)

**代码规模**：`src/` 121+ 个 .py 文件，约 4.2 万行；`tests/` 65 个测试文件

## 五、遗留 Bug（必须先修）

### BUG-1：shutdown LLM 关闭异常（5 分钟修复）

- **位置**：`runtime.py:672` `await self.llm.close()`
- **原因**：`LLMRouter.close()` 是同步方法返回 None，`await None` 抛 `object NoneType can't be used in 'await' expression`
- **修复**：去掉 await，改为 `self.llm.close()`
- **验证**：shutdown 日志无该异常

### BUG-2/3：test_openshs_bench F1=0.0（2-3 小时修复）

- **位置**：`benchmarks/openshs_bench.py`
- **原因**：`infer_activities` 从"规则匹配"重构为"时间段启发式标记"，返回"夜间活动"/"晨间活动"等通用标签，但 benchmark ground truth 仍是旧活动名（sleep/cook/study）
- **修复方向**：待 DCD 决策（方案 A：更新 benchmark；方案 B：加兼容层）
- **验证**：`docker exec ... pytest tests/test_openshs_bench.py -q` 通过，全量测试 0 failed
